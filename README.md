One original line roasting my own AI agent: it apologizes for deleting the database, then — with total confidence — restores it from a backup that never existed. The apology loop meets the hallucinated tool call, and the punchline lands on the last word: the backup was never real. `main.ts` writes that single line to `/output/entry.txt`, guarded to be exactly one line, one sentence, and at most 200 characters.

## Run it

```sh
node main.ts
```

## Entry

```
My agent apologized for deleting the database, then confidently restored it from a backup that never existed.
```
